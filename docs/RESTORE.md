# الرجوع لنسخة احتياطية

قبل كل تعديل كبير تنحفظ نسخة من المستودع بـ **tag**. الـ tag ما يتغير، حتى لو تغيّر الفرع `main` بعدين.

| الـ tag | شنو بيه |
|---|---|
| `backup/main-2026-11-14` | الفرع `main` مثل ما كان قبل إصلاحات 0.2.0، وهو أول نسخة من المشروع |
| `backup/feature-parked-cars-2026-11-14` | الفرع `feature/parked-cars-and-speed` قبل الدمج |

## من الموبايل (موقع GitHub)

**حتى تشوف النسخة:** افتح المستودع، واضغط على اسم الفرع (`main`)، واختار تبويب **Tags**، واختار الـ tag.

**حتى ترجعها كفرع مستقل:** وانت فاتح الـ tag، اكتب اسم جديد بمربع الفروع، مثلاً `restore-0.1.0`، واضغط **Create branch from …**.

**حتى ترجّع `main` بالكامل:** اطلب من المساعد يرجّعه. هذي العملية تمسح التعديلات الأحدث من `main`، بس تبقى محفوظة بالـ tags والفروع.

## من سطر الأوامر

```bash
# فرع جديد من النسخة الاحتياطية (آمن، ما يمسح شي)
git fetch --tags
git switch -c restore-0.1.0 backup/main-2026-11-14

# ترجيع main بالكامل (يمسح التعديلات الأحدث من main)
git switch main
git reset --hard backup/main-2026-11-14
git push --force-with-lease origin main
```
